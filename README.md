# GitHub User Finder

**Автор:** Анна Ткаченко

## Описание программы


Приложение для поиска пользователей GitHub с возможностью сохранения избранных профилей. Использует официальный GitHub API для получения данных о пользователях.

## Функциональность

* Поиск пользователей GitHub по логину
* Отображение информации: логин, имя, местоположение
* Добавление пользователей в избранное
* Сохранение избранного в JSON-файл
* Валидация ввода (проверка на пустое поле)
## Требования

* Python 3.8 или выше
* Библиотеки из `requirements.txt`

## Позитивные сценарии

## Пример 1. Успешный поиск и добавление существующего пользователя
Запустите приложение: python main.py.
В поле «Поиск пользователя GitHub» введите корректный логин, например: octocat.
Нажмите кнопку «Найти».
В таблице «Результаты поиска» отобразится информация о пользователе:
Логин: octocat
Имя: The Octocat
Локация: San Francisco
Выделите строку с найденным пользователем в таблице.
Нажмите кнопку «Добавить в избранное».
Вы увидите всплывающее сообщение: «Пользователь octocat добавлен в избранное!».
Нажмите кнопку «Показать избранное» — пользователь octocat появится в таблице «Избранное».
Результат: Пользователь успешно найден и сохранён в JSON‑файл.

## Пример 2. Просмотр избранного после перезапуска приложения
Закройте приложение.
Откройте его снова: python main.py.
Нажмите кнопку «Показать избранное».
В таблице «Избранное» отобразится ранее добавленный пользователь octocat.
Результат: Данные корректно загружаются из файла users.json при старте программы.

Негативные сценарии
## Пример 3. Попытка поиска с пустым полем
Запустите приложение.
Не вводите ничего в поле поиска.
Нажмите кнопку «Найти».
Ожидаемый результат: Появится всплывающее окно с ошибкой: «Ошибка: Поле поиска не должно быть пустым!». Поиск не выполняется.

## Пример 4. Поиск несуществующего пользователя
В поле поиска введите заведомо несуществующий логин, например: thisuserdoesnotexist12345.
Нажмите кнопку «Найти».
Ожидаемый результат: Появится всплывающее окно с сообщением: «Ошибка: Пользователь не найден (код: 404)». Таблица результатов останется пустой.
